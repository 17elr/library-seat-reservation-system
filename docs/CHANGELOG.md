# 更新记录

## 0.1.0 · 2026-10-10

### 功能

- 学生端完成预约、签到、暂离、返回、签退、取消、记录查询、违约查询、公告规则及修改密码。
- 管理员端完成概览统计、场地维护、开放日期、学生管理、预约关闭、违约撤销、公告、规则版本和操作日志。
- 选座支持编号搜索、插座 / 靠窗组合筛选，自动选座遵守当前筛选条件。
- 个人预约支持日期和进行中筛选；详情页展示事件时间线及状态倒计时。
- 特殊开放日期可直接编辑；闭馆时禁用无需填写的时间字段。
- 管理员填写原因重置学生密码后，旧登录失效；本人改密也退出其他已登录会话。

### 修复

- 快速切换阅览室和日期时，旧响应不再覆盖当前页面。
- 预约详情到期自动获取最终状态，提交期间倒计时不再重新启用按钮。
- 正确读取闭馆与违约撤销状态字段。

### 仓库

- 整理首页、界面预览、目录说明、部署文档与架构文档。
- 添加 GitHub Actions 自动测试与打包、问题反馈及 Pull Request 模板。
- 排除构建产物、本地数据、个人毕业材料及重复交付包。
